# 📚 Product Blueprint - Multimodal Chatbot

Bienvenido a la documentación técnica del proyecto **Multimodal Chatbot**. Este directorio contiene los planos (blueprints) del sistema, desde la concepción del problema hasta las estrategias de evaluación, seguridad y testing.

## 🗺️ Navegación

*   **[00_FOUNDATION](./00_FOUNDATION/):** El problema, la visión, los objetivos y el glosario de conceptos clave (LLM Multimodal, Whisper, Base64, LLM-as-a-Judge).
*   **[01_DESIGN_SYSTEM](./01_DESIGN_SYSTEM/):** Diagramas de arquitectura (Mermaid), flujo de datos multimodal y principios de diseño (SOLID, Registry Pattern).
*   **[02_COMPONENTS](./02_COMPONENTS/):** Contratos de la API (entrada/salida), reglas de negocio del motor multimodal y modelos de datos.
*   **[03_SECURITY_AND_AUDIT](./03_SECURITY_AND_AUDIT/):** Plan de seguridad, validación de archivos, manejo de secretos, evaluación con LLM-as-a-Judge y estrategia de testing con mocks.
